# StudyLedger

Academic intelligence platform. Ground-up rebuild (Sept 2026).

## Stack

- Next.js 16 (App Router) · React 19
- Tailwind CSS v4
- TypeScript (strict)
- Supabase (auth + Postgres) — fresh project
- Anthropic SDK

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run typecheck && npm run build
```
